# 소개팅 (SOMEON, 개발 때 이름 Drive Mate) 개요

> 이동하는 일상 속 새로운 인연을 연결하는 모빌리티 소셜 매칭 플랫폼

## 1. 차량 특화성

**장점**
- 출퇴근 및 이동이라는 일상적인 차량 이용 시간을 새로운 소셜 경험으로 전환
- 차량 위치 및 내비게이션 정보를 활용해 사용자의 생활권과 이동 목적에 맞는 만남 장소 추천
- 차량 음성 인터페이스를 활용한 핸즈프리 기반 소통 환경 제공

**단점**
- 운전 중 소개팅 상대를 탐색하거나 매칭을 진행하는 것은 안전성 측면에서 부적절
- 차량에서 제공해야 할 서비스와 스마트폰 기반 소개팅 서비스의 차별성이 명확하지 않을 수 있음

**보완 방안**
- 차량 이동 정보를 매칭에 활용
  - 사용자의 출퇴근 시간대, 주요 생활권, 이동 목적 등 동의된 정보를 활용해 생활 패턴이 유사한 상대 추천
  - 단순 위치 기반 매칭이 아닌 일상적인 이동 패턴을 고려한 매칭 제공
- 주행 상태에 따른 기능 차등 적용
  - 주행 중 프로필 탐색, 매칭 승인 등 시각적·조작 중심 기능 제한
  - 정차 상태에서 프로필 확인 및 매칭 진행
  - 주행 중에는 안전성이 검증된 범위에서 음성 안내 등 제한적인 기능 제공

## 2. 창의성

**장점**
- 자동차를 단순한 이동 수단에서 새로운 인연을 연결하는 소셜 플랫폼으로 확장
- 기존 외모 및 취미 중심의 매칭에서 벗어나 이동 시간과 생활 패턴을 활용한 새로운 매칭 방식 제안
- 차량의 이동 맥락과 소셜 서비스를 결합한 새로운 모빌리티 서비스 경험 제공

**단점**
- 기존 소개팅 앱에서도 충분히 구현할 수 있는 기능으로 보일 수 있으며, 자동차에서 서비스를 제공해야 하는 필연성이 부족할 수 있음
- 단순히 차량 디스플레이에 기존 소개팅 앱을 구현하는 수준이라면 차별성 확보가 어려움

**보완 방안**
- 이동 맥락 기반 차별화된 매칭
  - 출퇴근 시간대, 생활권, 이동 목적 등 차량 이용 특성을 매칭 요소로 활용
  - 유사한 생활 패턴을 가진 사용자 간 연결을 통해 기존 소개팅과 차별화
- 온라인 매칭에서 오프라인 만남까지 연결
  - 사용자 간 매칭 이후 공통 생활권 및 목적지를 고려한 만남 장소 추천
  - 차량 내 내비게이션과 연계해 실제 만남으로 이어지는 서비스 경험 제공

## 3. 기술 활용성

**활용 가능 SDK 및 기능**

| SDK | 활용 방안 |
|---|---|
| Vehicle SDK | 주행·정차 상태 확인 및 상태에 따른 서비스 기능 제어 |
| FusedLocation SDK | 사용자 동의 기반 위치 및 생활권 정보 활용 |
| NaviHelper SDK | 목적지 및 주변 장소 정보 연계, 만남 장소 추천 |
| TTS / STT SDK | 음성 기반 서비스 안내 및 대화 인터페이스 |

**개발 우선순위 및 고려사항**
- 1차 개발: Vehicle SDK를 활용한 주행·정차 상태별 UI 제어 및 기본 매칭 기능 구현
- 2차 개발: FusedLocation SDK를 활용한 생활권 기반 매칭 기능 구현
- 확장 개발: NaviHelper SDK를 활용한 만남 장소 추천 및 내비게이션 연계
- TTS / STT를 활용한 음성 인터페이스는 안전성 및 SDK 지원 범위를 고려해 단계적으로 적용

※ 초기 프로토타입에서는 핵심 매칭 기능과 차량 상태 연동에 집중하고, 내비게이션 기반 장소 추천은 후속 확장 기능으로 설정

(이 우선순위를 검토해 다시 정한 개발 순서는 [ROADMAP.md](ROADMAP.md)에 있음)

## 4. 사업성

**장점**
- 기존 모바일 소개팅 시장과 차별화된 차량 이용자 대상 소셜 서비스 시장 발굴
- 차량 내 앱 생태계 확장에 따른 신규 서비스 수요 창출 가능
- 사용자 기반 확보 시 카페, 레스토랑, 데이트 장소 등 지역 상권과의 제휴 가능
- 향후 소개팅뿐 아니라 공통 관심사 및 취미 기반 소셜 매칭으로 서비스 확장 가능

**고려사항 및 보완 방안**
- 초기 사용자 확보를 위해 특정 지역 및 차량 이용자를 대상으로 서비스 운영 및 수요 검증
- 본인 인증, 신고·차단, 개인정보 보호 등 신뢰성 확보 체계 마련
- 지역 제휴 매장 및 만남 장소 추천을 통한 부가 수익 모델 확보
- 소개팅을 핵심 서비스로 시작하고 취미·라이프스타일 기반 매칭으로 확장

## 5. 핵심 차별화 방향

기존 소개팅 서비스가 사용자의 직접적인 검색과 프로필 탐색을 중심으로 한다면, SOMEON은 차량의 이동 정보와 생활 패턴을 활용해 새로운 인연을 연결하는 서비스임.

> 이름: SOMEON(썸온) = Some(썸) + ON(켜다). 슬로건 "당신의 일상에 썸을 켜다."

차량을 단순한 이동 공간에서 일상 속 새로운 관계가 시작되는 모빌리티 소셜 플랫폼으로 확장
